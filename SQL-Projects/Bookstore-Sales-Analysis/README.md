# Bookstore Sales Analysis

**Status:** Runnable SQLite demo

## Overview
Two tables (books and sales) with 30 synthetic books and 100 synthetic sales transactions. Business revenue and ranking queries.

## Files
`schema_and_data.sql`, `analysis_queries.sql`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Earlier work requested more records; these newly generated records are not the original earlier dataset.
