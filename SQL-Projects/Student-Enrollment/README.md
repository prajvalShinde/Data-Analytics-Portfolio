# Student Enrollment SQL

**Status:** Runnable SQLite demo

## Overview
Two-table students/enrollments schema with 50 synthetic students and 100 synthetic enrollments.

## Files
`schema_and_data.sql`, `analysis_queries.sql`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Original earlier 200-row records are not included.
