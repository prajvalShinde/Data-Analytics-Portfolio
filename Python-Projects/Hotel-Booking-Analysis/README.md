# Hotel Booking Analysis

**Status:** Runnable synthetic-data demo

## Overview
Simple hotel cancellation, ADR, and monthly booking analysis.

## Files
`hotel_analysis.py`, `synthetic_hotel_bookings.csv`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Synthetic data only; not a claim about real hotels.
