# Sales Analysis System

**Status:** Runnable new illustrative implementation

## Overview
Menu-driven analysis of eight synthetic retail records; revenue, profit, category, region, quantity and threshold filtering.

## Files
`sales_analysis.py`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Sales is computed as price × quantity. Profit values are synthetic provided fields.
