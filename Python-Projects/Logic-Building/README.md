# Python Logic Building

**Status:** Six runnable examples

## Overview
Basic loops, conditions, number properties and patterns.

## Files
`factorial.py`, `palindrome.py`, `armstrong.py`, `prime.py`, `reverse_number.py`, `star_patterns.py`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Document real results only after running the analysis on the final dataset.
