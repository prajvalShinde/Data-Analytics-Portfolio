# Student Management System

**Status:** Runnable reconstructed example

## Overview
In-memory student CRUD, duplicate ID checks, marks analysis, and pass/fail threshold of 40.

## Files
`student_management.py`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Records disappear when the program closes; no database or file persistence.
