# Hypothesis Testing, P-value and Margin of Error

**Status:** Runnable code (dependencies required)

## Overview
One-sample two-sided t-test of student marks against a hypothesized mean of 75. Includes standard error, 95% margin of error and confidence interval.

## Files
`hypothesis_testing.py`, `requirements.txt`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Assumes independent observations and an approximately normal population for small-sample inference. Failure to reject H0 does not prove H0.
