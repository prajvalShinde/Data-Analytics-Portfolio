## Getting started
Install Python 3. Run scripts from a terminal, e.g. `python Python-Projects/Student-Management-System/student_management.py`. For SQL, use SQLite and execute `schema_and_data.sql` before `analysis_queries.sql`. Hypothesis testing requires `pip install -r Statistics-Projects/Hypothesis-Testing/requirements.txt`.
