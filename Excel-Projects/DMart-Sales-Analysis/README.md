# DMart Sales Analysis

**Status:** Starter documentation and synthetic CSV only

## Overview
Analyze sales, quantity, profit and category performance.

## Files
`synthetic_retail_sales.csv`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
Open CSV in Excel, format as a Table, check data quality, build PivotTables, PivotCharts, slicers and a dashboard. Add your completed `.xlsx` workbook and actual insights before marking complete.
