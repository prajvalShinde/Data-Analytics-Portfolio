# Excel dashboard steps

1. Open the synthetic CSV in Excel (replace with your original permitted dataset when available).
2. Check blanks, duplicates, data types and outliers.
3. Select the data and create a Table (Insert > Table).
4. Create PivotTables for categories, locations and key metrics.
5. Create charts and insert slicers where supported.
6. Arrange KPI cells and visuals on a Dashboard worksheet.
7. Write three insights supported by your actual PivotTable results.
8. Save the completed `.xlsx` and add dashboard screenshots.

**No completed workbook is included in this ZIP.**
