# Sales Analysis Power BI Dashboard

**Status:** Design specification only; no PBIX

## Overview
Proposed dashboard: revenue, profit, units, product/category performance and regional filters.

## Files
`example_measures.dax`, `DASHBOARD_PLAN.md`

## How to use
Read the files and run the included scripts with Python 3 or a compatible SQL environment. Data files marked **synthetic** are demonstration data, not original datasets.

## Notes
DAX assumes the named tables and columns exist; rename as required. Create `.pbix` and add screenshots after building.
