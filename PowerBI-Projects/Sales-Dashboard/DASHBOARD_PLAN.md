# Power BI build plan

1. Import and inspect the final dataset.
2. Clean and type columns using Power Query.
3. Build relationships and validate filter directions.
4. Add DAX measures from `example_measures.dax`, adapting field names.
5. Create KPI cards, bar/column charts, a time trend if dates exist, and slicers.
6. Test filters and reconcile totals against source data.
7. Save the `.pbix`, export screenshots, and document verified insights.

**This folder is a specification, not a finished dashboard.**
